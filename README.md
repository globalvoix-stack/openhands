🙌 Welcome to Thinksoft, an AI-driven development platform based on [OpenHands](https://github.com/OpenHands/OpenHands).

Thinksoft provides the same powerful features as OpenHands, customized for your needs:

### Thinksoft Local GUI
Use the Local GUI for running agents on your laptop. It comes with a REST API and a single-page React application.
The experience will be familiar to anyone who has used Devin or Jules.

[Check out the OpenHands docs](https://docs.openhands.dev/openhands/usage/run-openhands/local-setup) for setup instructions.

### Software Agent SDK
The SDK is a composable Python library that contains all of the agentic tech. It's the engine that powers Thinksoft.

Define agents in code, then run them locally, or scale to 1000s of agents in the cloud.

[Check out the docs](https://docs.openhands.dev/sdk) or [view the source](https://github.com/OpenHands/software-agent-sdk/)

### CLI Interface
The CLI is an easy way to start using Thinksoft. The experience will be familiar to anyone who has worked
with e.g. Claude Code or Codex. You can power it with Claude, GPT, or any other LLM.

[Check out the docs](https://docs.openhands.dev/openhands/usage/run-openhands/cli-mode) or [view the source](https://github.com/OpenHands/OpenHands-CLI)
